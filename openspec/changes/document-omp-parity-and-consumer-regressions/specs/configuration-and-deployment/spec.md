# Spec Delta

## ADDED Requirements

### Requirement: Current OMP Parity Documentation And Evidence

Current integration docs SHALL describe the approved native-OMP/OpenCode parity behavior, distinguish historical governance designs and record evidence by source/mock/native/image/platform level. Manual native/shared skill-root configuration and the prohibition on generated OMP YAML SHALL be documented.

#### Scenario: Current inventory
- **WHEN** the 37-item feature inventory is consulted
- **THEN** every item SHALL state its retained/removed/simplified disposition, actual behavior and applicable evidence limitations.

#### Scenario: Upstream discovery correction
- **WHEN** OpenCode custom tools/plugins are documented
- **THEN** current docs SHALL distinguish upstream workspace discovery from absence of project-owned executable preflight.

#### Scenario: Evidence report
- **WHEN** native smoke or image checks are reported
- **THEN** the agent version and exercised layer SHALL be stated and unexercised model, proxy, architecture or platform behavior SHALL remain explicitly unverified.
