# Spec Delta

## Purpose

Provides native deny-all omp intent profile as a complete observable prerequisite for safe email authorization or durable autonomous delivery within the approved platform boundary.

## ADDED Requirements

### Requirement: Native OMP intent denial

The OMP intent profile SHALL block every native tool name at the pinned synchronous pre-dispatch extension hook, independently of ACP permission callbacks.

#### Scenario: Mapped and unknown tools

- **WHEN** real native OMP receives scripted read, bash, web_search, skill and custom unknown tool calls
- **THEN** every call is blocked before execution with zero file/network/skill effects

### Requirement: Authored isolated native assets

Intent launches SHALL use authored native settings, the existing generated ESM bundle and a private copy of authored model configuration without importing user sessions or mailbox credentials.

#### Scenario: Development and image launch

- **WHEN** the selected intent profile is started with a fixture model
- **THEN** native catalog selection works, authored source bytes stay unchanged and normal restricted/native-yolo launches keep existing behavior
