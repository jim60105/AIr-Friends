## Why

The current web dashboard UI is quite ugly and needs a modern redesign to improve the user experience. This redesign focuses strictly on UI/UX improvements while maintaining all existing functional requirements intact. A better aesthetic and user flow will make interacting with the dashboard more pleasant and efficient.

## What Changes

- Redesign the layout and styling of the web dashboard.
- Update CSS/HTML components for a more modern look and feel.
- Keep all functional endpoints and underlying logic unchanged.
- Ensure the new design follows the web design guidelines for frontend design.

## Capabilities

### New Capabilities
- `dashboard-ui`: Modernized UI and UX for the web dashboard.
