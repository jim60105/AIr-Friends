## Why

The web dashboard has four bugs that make core features non-functional: workspace file browsing returns 400 errors due to a path format mismatch between the tree builder and file handler, the chat model dropdown is hardcoded instead of reflecting `modelRouting` config, sending chat messages fails because the frontend uses `message` while the API expects `content`, and session audit lookups fail because the completed session store uses a different ID format (`{type}_{timestamp}`) than the audit logger (`sess_*`).

## What Changes

- **Fix workspace file path mismatch**: `buildDirectoryTree` generates paths with leading `/` (e.g., `/journal/2026-02-23.md`), but `handleWorkspaceFile` rejects paths starting with `/`. Strip leading slash from the path before validation.
- **Populate model dropdown from `modelRouting` config**: Add a `/api/config/models` endpoint that extracts unique model names from `modelRouting.rules` and the default `agent.model`, then populate the `<datalist>` dynamically on page load.
- **Fix chat message field name**: Change `chat.js` `chatSend()` to send `{ chatSessionId, content: msg }` instead of `{ chatSessionId, message: msg }`.
- **Fix session audit ID mismatch**: Store the actual skill-API session ID (`sess_*`) in `CompletedSession` so audit file lookups succeed, or use both IDs and search with the correct one.
