# Git 自動備份

AIr-Friends 內建自動化 Git 備份工作流程，能夠定期將使用者的記憶資料、全域筆記與重要組態狀態自動推播至遠端 Git 專案庫。

---

## 運作流程

1. **資料目錄即 Git 專案庫**：資料儲存目錄（`data/`）可被初始化為標準 Git 儲存庫。
2. **自動定時提交**：備份排程器定期檢查目錄異動，自動執行 `git add`、生成帶有時間戳記的提交訊息並執行 `git commit`。
3. **安全推播至遠端**：透過預先配置好的 HTTPS 或 SSH 憑證，將異動推播至遠端儲存庫（如 GitHub / GitLab 私有專案庫）。

---

## 推薦的標準 `.gitignore` 範本

備份服務本身不會擅自修改資料目錄下的 `.gitignore` 檔案。維運人員必須自行維護 `{dataDir}/.gitignore`，以避免暫存檔案或日誌被誤納入版本控制：

```gitignore
# 排除所有暫存目錄
tmp/
*/tmp/
workspaces/*/tmp/

# 排除即時執行階段日誌與稽核日誌
*.log
logs/
audit/

# 排除本機快取與鎖定檔
.cache/
*.lock
```

將此範本存放在你的資料目錄根目錄中，能確保備份內容僅專注於珍貴的記憶 JSONL、Markdown 筆記與自訂設定。
