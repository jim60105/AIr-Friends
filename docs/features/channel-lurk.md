# 頻道潛水監聽

「頻道潛水（Channel Lurk）」功能讓機器人能夠在不被直接標記的情況下，安靜觀察頻道對話，並在適當時機自然地加入討論。

---

## 運作原理

1. **背景訊息監聽**：機器人接收指定頻道內的所有日常對話事件，但預設不發言。
2. **訊息暫存與意圖偵測**：將收到的對話暫存至近期訊息佇列中。
3. **加入討論評估 (Joining Criteria)**：
   - 關鍵字觸發：對話中出現機器人高度關心的特定話題、專有名詞或機器人的名字（即使未附帶 `@` 提及）。
   - 疑問句識別：當使用者提出公開疑問且其他成員尚未回答時。
   - 機率判定：透過機率門檻控制介入頻率，避免搶話或造成使用者困擾。

---

## 隱私與安全界線

- **僅限指定公開頻道**：頻道潛水功能預設關閉，且只能在組態明確啟用的公開頻道中運作，嚴禁在私密對話或未授權頻道中啟用。
- **無跨頻道資料洩漏**：潛水收集到的短期脈絡僅供該特定頻道之情境理解，絕不會流出至其他使用者的私密記憶庫。
