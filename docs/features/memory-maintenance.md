# 記憶維護整理

為了讓長期記憶保持精簡且高關聯性，AIr-Friends 具備智慧化的記憶維護與定期整理機制。

---

## 語彙索引檢索 (`indexed-memory.ts`)

AIr-Friends 在底層採用倒排索引（Inverted Index）與 BM25 / TF-IDF 演算法來進行記憶檢索：

- **高效純文字檢索**：無須架設龐大且昂貴的向量資料庫（Vector Database），不產生額外的向量嵌入（Embedding）API 運算費用。
- **在地化分詞技術**：整合 Jieba 原生分詞引擎，精準處理繁體中文人名、專有名詞與標籤。
- **無向量資料庫聲明**：系統的記憶檢索完全基於語彙索引與結構化 JSONL 儲存，徹底排除外部向量嵌入依賴。

---

## 背景 LLM 記憶整併與修補

隨著對話進行，記錄的碎片事實會逐漸增加。系統支援由排程器觸發的背景記憶維護工作階段（`memory_maintenance`）：

1. **背景會話啟動**：在離峰時段自動針對活躍使用者的記憶庫啟動整理會話。
2. **語意合併與精簡**：
   - 找出內容重複或互相矛盾的事實（例如「使用者喜歡喝紅茶」與後來的「使用者改喝綠茶」）。
   - 將碎片事實整合成精簡的單一核心事實。
3. **記憶修補 (Patching)**：
   - 代理人調用專屬的記憶修補技能，更新或刪除過時的 JSONL 記憶條目。
   - 保留記憶的類別標籤與權重等級，確保後續載入與搜尋的準確度。
