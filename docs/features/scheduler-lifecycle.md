# 排程器生命週期

AIr-Friends 擁有統一的共用背景排程器（Scheduler），負責驅動定時提醒、自發貼文、記憶維護與 Git 備份等各項非同步任務。

---

## 統一生命週期管理

所有定時任務均向全域排程中心註冊，並遵循以下生命週期規則：

- **啟動階段**：系統開機完成並連線至聊天平台後，排程器依序啟動各項任務計時器。
- **優雅關閉階段 (Graceful Shutdown)**：當收到 `SIGTERM` 或 `SIGINT` 信號時，排程器會立即暫停派發新任務，並等待執行中的代理人工作階段完成寫入後才安全退出。

---

## 重啟補償機制 (Restart Catchup)

若系統因維護重新開機或臨時斷線，部分預定執行的排程任務（特別是定時提醒）可能在離線期間到期：
- 排程器在啟動初始化時，會主動掃描尚未執行的歷史到期項目。
- 針對錯過的任務，系統會立即排入補發佇列（Catchup Execution），依序執行並通知使用者，避免重要約定因伺服器重開而永久遺失。

---

## 隨機間隔抖動 (Jitter)

為了防止多項排程任務在整點時同時被觸發，造成主機 CPU 飆高或引發外部 API（如 Discord Gateway）的速率限制：
- 排程器會在每次計算下次執行間隔時，動態注入隨機時間抖動（Jitter）。
- 抖動範圍通常在基礎間隔的 ±10% 至 ±20% 之間，分散並平滑化系統的負載峰值。
