# 對話與互動

AIr-Friends 專為社群對話環境設計，支援多種互動情境與靈活的對話模式。

---

## 互動型態 (Interaction Modalities)

### 1. 標記觸發 (Mentions)
在群組或伺服器公開頻道中，直接提及機器人（例如 `@AIr-Friends 你好` 或 Misskey 的提及語法）即可觸發對話。
- 機器人收到標記後，會立即在該頻道發送「輸入中（Typing）」狀態，並啟動代理人工作階段進行推理。
- 代理人回覆時，會自動引用原訊息或提及提問者。

### 2. 私密對話 (Direct Messages / Private Notes)
在 Discord 私訊或 Misskey Direct 筆記中，使用者無須特別輸入 `@機器人`，任何輸入訊息都會直接被視為觸發指令：
- 私訊對話同樣受到工作區目錄隔離保護（`repo/workspaces/{platform}/{userId}`）。
- 私訊互動具備最高的隱私性，不會受限於一般頻道的全域回覆限制。

### 3. 討論串處理 (Threads)
在 Discord 討論串或 Misskey 貼文回覆串（Thread）中：
- 若使用者在討論串內標記機器人，機器人會自動繼承並在同一個討論串內繼續作答。
- 系統會自動抓取該討論串最近的歷史訊息作為脈絡輔助資訊，避免對話出現語意斷層。

---

## 對話體驗與行為特點

- **自然語言互動**：機器人具備設定好的角色性格（Soul Prompt），不會以生硬的 AI 模板口吻回答，而是展現生動的專屬風格。
- **工具呼叫回饋**：當代理人需要查詢記憶、網路搜尋或執行技能時，機器人會在背景靜默完成或發布適當的進度反應，最終給出整合後的流暢回覆。
- **多行與排版相容**：回覆訊息自動轉換為各平台支援的最佳 Markdown 格式（程式碼區塊、粗體、清單）。若單次回答長度超過平台上限（例如 Discord 2000 字元限制），系統會自動進行安全的智慧分段發送。
