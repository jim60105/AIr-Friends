# 對話脈絡與重設

在人機對話過程中，維持清晰且不過度冗長的對話脈絡（Context）對於降低 Token 成本與提高回應品質至關重要。

---

## 對話脈絡組合機制

每當使用者觸發對話時，AIr-Friends 會在底層自動組合即時提示詞脈絡：

1. **核心記憶 (Core Tier Memories)**：使用者最重要的背景資訊、偏好與常設設定（受權杖預算保護）。
2. **工作層記憶 (Working Tier Memories)**：最近幾次互動留下的重點紀錄。
3. **快速回想記憶 (Fast Recall)**：根據本次觸發訊息的關鍵字，動態檢索出的高度相關歷史紀錄。
4. **近期頻道訊息 (Recent Messages)**：固定載入最近 20 則頻道歷史訊息，讓機器人理解當前話題走向。
5. **角色設定與靈魂提示詞 (Soul Prompt)**：注入角色的性格規範、說話口氣與核心行為守則。

---

## 重設指令 (`/clear`)

當對話時間較長、話題切換，或你希望讓機器人拋開先前的對話包袱重新開始時，可以使用 `/clear` 指令。

### 使用方式
在頻道或私訊中直接發送：

```text
/clear
```

### 重設行為
- **立即重設對話脈絡**：清除先前的近期訊息關聯與暫存脈絡。
- **無須等待推論**：系統辨識出純 `/clear` 訊息後，會直接完成重設並結束，不會呼叫代理人產生不必要的文字廢話。
- **保留核心記憶**：`/clear` 僅重設當前會話的短期脈絡，不會抹除你已儲存的重要長期記憶（如偏好、名字等）。
- **後續快速回想錨點**：`/clear` 之後的訊息將建立全新的對話歷史基準線，讓未來的快速回想功能更加精準聚焦。
