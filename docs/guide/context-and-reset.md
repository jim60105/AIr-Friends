# 對話脈絡與重設

在人機對話過程中，維持精簡且聚焦的對話脈絡（Context）有助於降低 Token 成本並提高回應品質。

---

## 對話脈絡組合機制

每當使用者觸發對話時，AIr-Friends 會在底層組合即時提示詞脈絡。

1. **核心記憶（Core Tier Memories）**：使用者最重要的背景資訊、偏好與固定設定，受 Token 預算保護。
2. **工作層記憶（Working Tier Memories）**：最近幾次互動留下的重點紀錄。
3. **快速回想記憶（Fast Recall）**：依本次觸發訊息的關鍵詞，動態檢索出的高度相關歷史紀錄。
4. **近期頻道訊息（Recent Messages）**：固定載入最近若干則頻道歷史訊息，預設 20 則（`memory.recentMessageLimit`）。
5. **角色設定與靈魂提示詞（Soul Prompt）**：注入角色的性格規範、說話口氣與核心行為守則。

---

## 重設指令（`/clear`）

當對話時間較長、話題切換，或你希望讓機器人拋開先前的對話重新開始時，可以使用 `/clear` 指令。

### 使用方式
在頻道或私訊中直接發送下列文字。

```text
/clear
```

### 重設行為
- **重設對話脈絡**：捨棄所有早於（含）最後一則 `/clear` 訊息的近期訊息。
- **無須等待推論**：系統辨識出觸發訊息為 `/clear` 後，會直接完成重設並結束，不呼叫代理人。
- **保留核心記憶**：`/clear` 僅重設短期脈絡，不會刪除已儲存的長期記憶（如偏好、名字等）。
- **建立新基準線**：`/clear` 之後的訊息成為新的對話歷史基準，後續快速回想會以此為範圍。
