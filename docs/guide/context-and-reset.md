# 對話脈絡與重設

在人機對話過程中，維持精簡且聚焦的對話脈絡（Context）有助於降低 Token 成本並提高回應品質。

---

## 對話脈絡組合機制

每當使用者觸發對話時，AIr-Friends 會在底層組合即時提示詞脈絡，五類來源各有分工。核心記憶（Core Tier Memories）收錄使用者最重要的背景資訊、偏好與固定設定，並受 Token 預算保護；工作層記憶（Working Tier Memories）收錄最近幾次互動留下的重點紀錄；快速回想記憶（Fast Recall）依本次觸發訊息的關鍵詞，動態檢索高度相關的歷史紀錄。

另外兩類來源與當下對話直接相關。近期頻道訊息（Recent Messages）固定載入最近若干則頻道歷史，預設 20 則（`memory.recentMessageLimit`）；角色提示詞則注入角色的性格規範、說話口氣與核心行為守則。

---

## 重設指令（`/clear`）

當對話時間較長、話題切換，或你希望讓機器人拋開先前的對話重新開始時，可以在頻道或私訊中直接發送下列文字。

```text
/clear
```

送出後，系統會捨棄所有早於（含）最後一則 `/clear` 訊息的近期訊息，並且不呼叫代理人，因此不需要等待推論。已儲存的長期記憶（如偏好、名字等）不受影響，`/clear` 之後的訊息則成為新的對話歷史基準，後續快速回想以此為範圍。
