# 記憶機制與體驗

AIr-Friends 具備獨特且高效的長期記憶架構。系統既不需要使用者手動輸入複雜的命令，也不依賴昂貴且易失真的外部向量資料庫。

---

## 記憶的分層架構

AIr-Friends 將使用者記憶分為三個主要層級：

| 記憶層級 (Tier) | 說明 | 載入時機與限制 |
| :--- | :--- | :--- |
| **Core（核心層）** | 使用者的身分偏好、重要約定、核心稱呼 | 每次對話優先完整載入（受 `coreMaxTokens` 限制，預設 512） |
| **Working（工作層）** | 最近互動摘要、當前進行中的專案細節 | 最新建立的數筆記憶（受 `workingMaxItems` 限制，預設 4 筆） |
| **Recall（回想層）** | 過去的特定事件、經驗與歷史紀錄 | 平時不主動載入，透過倒排索引與語彙搜尋按需檢索 |

---

## 自動記錄與記憶搜尋

### 1. 自動摘要記錄
在與機器人交流的過程中，當對話出現關鍵事實或偏好（例如「我對花生過敏」、「我目前在學習 Rust」），代理人會在背景透過 `memory-save` 技能自動將事實儲存為結構化記憶項目。

### 2. 記憶搜尋 (`memory-search`)
當使用者問起過去的事情（例如「你還記得我上次說想讀哪本書嗎？」）：
- 代理人會透過純文字倒排索引引擎快速搜尋記憶儲存庫。
- 檢索機制結合 Jieba 原生分詞技術與語彙關聯評分，能精準比對人名、書名與專有名詞。

### 3. 全域代理人知識庫 (Agent Workspace)
除了一般使用者個人的私人記憶外，機器人還擁有全域共用的知識庫（`agent-workspace/notes/`）。當機器人在不同會話中累積了通用的客觀知識或技術筆記，會整理收錄於此，讓所有人都能受益於代理人的持續自我成長。

---

## 隱私隔離與頻道寫入政策

- **使用者絕對隔離**：使用者 A 的私人記憶嚴禁且無法被使用者 B 檢索或存取。
- **頻道記憶唯讀原則**：公開頻道的討論雖然可供機器人讀取脈絡，但使用者私密個人資料預設僅能從與該使用者的對話中建立，防止公私領域記憶混淆。
- **匯出與清除**：使用者隨時可以要求機器人列出所記錄的記憶內容，並可要求刪除特定的過期記憶。
