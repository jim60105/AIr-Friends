# 記憶機制與體驗

AIr-Friends 具備長期記憶架構，使用者不需手動輸入複雜命令，系統也不依賴外部向量資料庫。

---

## 記憶的分層架構

AIr-Friends 將使用者記憶分為三個層級。

| 記憶層級 (Tier) | 說明 | 載入時機與限制 |
| :--- | :--- | :--- |
| **Core（核心層）** | 使用者的身分偏好、重要約定、核心稱呼 | 每次對話優先完整載入（受 `coreMaxTokens` 限制，預設 512） |
| **Working（工作層）** | 最近互動摘要、當前進行中的專案細節 | 載入最新建立的數筆記憶（受 `workingMaxItems` 限制，預設 4 筆） |
| **Recall（回想層）** | 過去的特定事件、經驗與歷史紀錄 | 平時不主動載入，透過語彙搜尋按需檢索 |

記憶以 JSONL 檔案附加寫入（`memory.public.jsonl` 與 `memory.private.jsonl`），檢索以 BM25 語彙評分搭配 jieba 分詞排序，不需要外部向量資料庫或嵌入 API。

---

## 自動記錄與記憶搜尋

### 自動摘要記錄

在與機器人交流的過程中，當對話出現關鍵事實或偏好（例如「我對花生過敏」、「我目前在學習 Rust」），代理人會在背景透過 `memory-save` 技能將事實儲存為結構化記憶項目。

### 記憶搜尋（`memory-search`）

當使用者問起過去的事情（例如「你還記得我上次說想讀哪本書嗎？」），代理人會透過語彙評分引擎搜尋記憶儲存庫。機制結合 jieba 分詞與語彙關聯評分，能比對人名、書名與專有名詞。

### 全域代理人知識庫 (Agent Workspace)

除了一般使用者個人的私人記憶外，機器人還擁有全域共用的知識庫（`agent-workspace/notes/`）。當機器人在不同會話中累積了通用的客觀知識或技術筆記，會整理收錄於此。

---

## 隱私隔離與頻道寫入政策

使用者 A 的私人記憶無法被使用者 B 檢索或存取。公開頻道的討論可供機器人讀取脈絡，頻道記憶的寫入由 `memory.channelWritePolicy` 控制，預設值 `sessions` 允許一般頻道會話寫入頻道記憶，條目具署名、可衰減、有上限且可由儀表板管理；`curated` 則拒絕使用者端寫入，改由維運流程建立。使用者可要求機器人列出所記錄的記憶內容，並可要求刪除特定的過期記憶。
